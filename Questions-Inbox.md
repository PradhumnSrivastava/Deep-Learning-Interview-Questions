
16. What is the difference between univariate, bivariate, and multivariate analysis? Ans- Univariate analysis examines one variable, bivariate analysis examines the relationship between two variables, and multivariate analysis examines multiple variables simultaneously.

17. What is the difference between mean, median, and mode? Ans- Mean is the arithmetic average, median is the middle value in ordered data, and mode is the most frequently occurring value. Median is generally less sensitive to extreme values than mean.

18. What is the difference between variance and standard deviation? Ans- Variance measures the average squared deviation from the mean, while standard deviation is the square root of variance and expresses dispersion in the original measurement units.

19. What is the Central Limit Theorem, and why is it important in Data Science? Ans- The Central Limit Theorem states that, under suitable conditions, the sampling distribution of the sample mean approaches a normal distribution as sample size increases, helping support statistical inference.

20. What is a p-value in hypothesis testing? Ans- A p-value is the probability, assuming the null hypothesis is true, of obtaining a result at least as extreme as the observed result. A small p-value provides evidence against the null hypothesis.

21. What is the difference between Type I and Type II errors? Ans- A Type I error occurs when a true null hypothesis is incorrectly rejected, while a Type II error occurs when a false null hypothesis is not rejected.

22. What is the difference between parametric and non-parametric statistical methods? Ans- Parametric methods rely on assumptions about the underlying distribution or model parameters, while non-parametric methods generally make fewer distributional assumptions.

23. What is feature engineering in Data Science? Ans- Feature engineering involves creating, transforming, or selecting input variables to represent useful information in a form that helps analytical or machine learning models perform better.

24. What is the difference between nominal, ordinal, interval, and ratio data? Ans- Nominal data represents categories without order, ordinal data has an order, interval data has meaningful differences but no true zero, and ratio data has both meaningful differences and a true zero.

25. What is dimensionality reduction in Data Science? Ans- Dimensionality reduction decreases the number of features while attempting to preserve important information, potentially improving computational efficiency, visualization, and model generalization.

26. What is Principal Component Analysis (PCA)? Ans- PCA is a linear dimensionality reduction technique that transforms correlated features into orthogonal principal components ordered by the amount of variance they explain.

27. What is the difference between descriptive statistics and inferential statistics? Ans- Descriptive statistics summarize and describe observed data, while inferential statistics use sample data to estimate population characteristics or test hypotheses about a larger population.

28. What is data provenance, and why is it important? Ans- Data provenance records where data originated, how it was collected, and how it was transformed. It supports traceability, reproducibility, auditing, and trust in analytical results.

29. What is the difference between batch processing and stream processing? Ans- Batch processing handles accumulated data in groups at scheduled intervals, while stream processing processes incoming data continuously or with very low latency.

30. What is reproducibility in a Data Science project? Ans- Reproducibility means that the same analysis can be repeated with the same data, code, dependencies, configuration, and relevant random seeds to obtain consistent results.
