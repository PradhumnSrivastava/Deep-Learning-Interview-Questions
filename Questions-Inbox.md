
103. What is a baseline model? Ans- A baseline model is a simple reference model used to evaluate whether a more complex model provides meaningful improvement.

104. What is a data sampling distribution? Ans- A sampling distribution is the probability distribution of a statistic calculated from repeated samples drawn from the same population.

105. What is the Law of Large Numbers? Ans- The Law of Large Numbers states that as the sample size increases, the sample average tends to approach the population mean under suitable conditions.

106. What is a likelihood function? Ans- A likelihood function measures how compatible observed data is with different parameter values of a statistical model.

107. What is Maximum Likelihood Estimation (MLE)? Ans- MLE estimates model parameters by selecting the values that maximize the likelihood of observing the given data.

108. What is Bayesian inference? Ans- Bayesian inference updates prior beliefs about a parameter using observed data to obtain a posterior probability distribution.

109. What is the difference between prior and posterior probability? Ans- Prior probability represents belief before observing new evidence, while posterior probability represents the updated belief after considering that evidence.

110. What is a probability density function (PDF)? Ans- A PDF describes the relative likelihood of values of a continuous random variable, and its integral over an interval gives the probability of that interval.

111. What is a cumulative distribution function (CDF)? Ans- A CDF gives the probability that a random variable is less than or equal to a specified value.

112. What is the difference between independent and mutually exclusive events? Ans- Independent events do not affect each other's probabilities, whereas mutually exclusive events cannot occur together; for events with positive probabilities, they are not independent.

113. What is conditional probability? Ans- Conditional probability is the probability of an event occurring given that another event has already occurred, expressed as P(A|B) = P(A ∩ B) / P(B), when P(B) > 0.

114. What is Bayes' theorem? Ans- Bayes' theorem updates the probability of an event using new evidence: P(A|B) = P(B|A)P(A) / P(B), when P(B) > 0.

115. What is the difference between covariance and correlation? Ans- Covariance measures how two variables vary together and depends on their units, whereas correlation measures the strength and direction of their linear relationship on a standardized scale.

116. What is a probability distribution? Ans- A probability distribution describes the possible values of a random variable and the probabilities associated with those values.

117. What is a Bernoulli distribution? Ans- A Bernoulli distribution models a single experiment with two possible outcomes, usually represented as 1 with probability p and 0 with probability 1 − p.

118. What is a binomial distribution? Ans- A binomial distribution models the number of successes in a fixed number of independent trials, each having the same probability of success.

119. What is a Poisson distribution? Ans- A Poisson distribution models the number of events occurring in a fixed interval when events occur independently at a constant average rate under the model's assumptions.
